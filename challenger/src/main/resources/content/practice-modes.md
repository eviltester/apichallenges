# API Practice Modes

Practice modes are the hands-on part of the site. Use them to send real requests, compare responses with expectations, and build confidence with different API behaviours.

## Choose A Practice Mode

| Practice Mode | What You Will Learn |
| --- | --- |
| [Simulation Mode](/practice-modes/simulation) | Request construction and response interpretation without changing server-side data. |
| [API Challenges](/apichallenges) | A guided challenge set for learning API operations, status codes, headers, and state changes. |
| [Simple API](/practice-modes/simpleapi) | Stateful CRUD practice with a small API that supports JSON, XML, and OpenAPI files. |
| [Buggy API](/practice-modes/shoppingcart) | How to investigate deliberately buggy behaviour in an API with more realistic business rules. |
| [Mirror Mode](/practice-modes/mirror) | How to inspect exactly what your client sends by having the server mirror request details back. |
| [API From Hell](/practice-modes/fromhell) | How tools and tests behave around awkward API design, unusual formats, and hostile edge cases. |

## Suggested Flow

Start in [Simulation Mode](/practice-modes/simulation), then move to the [Simple API](/practice-modes/simpleapi) for persistent data. Use [API Challenges](/apichallenges) to practise coverage, then review the [Challenge Solutions](/apichallenges/solutions) after you have attempted the scenarios yourself.
