# Node Express

Standalone API From Hell implementation using Express.

Run from this folder:

```bash
npm install
npm start
```

Configuration:

- `PORT`, default `3001`
- `FROMHELL_PREFIX`, default `/fromhell`
- `FROMHELL_CATALOG`, default `../../catalog/fromhell-catalog.json`

Express may normalize some deliberately awkward responses, especially no-body status codes.
