# Node Native HTTP

Standalone API From Hell implementation using Node.js built-in `http`.

Run from this folder:

```bash
node server.js
```

Or from `api-from-hell`:

```bash
node implementations/node-native-http/server.js
```

Configuration:

- `PORT`, default `3001`
- `FROMHELL_PREFIX`, default `/fromhell`
- `FROMHELL_CATALOG`, default `../../catalog/fromhell-catalog.json`
